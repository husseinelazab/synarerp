# برنامج مزامنة الموازين

يحدّث أسعار الأصناف الموزونة في موازين طباعة الملصقات تلقائياً كلما تغيّر سعر في سِينار.

## كيف يعمل
- يعمل على جهاز في الفرع (ويندوز أو لينكس، Python 3.8+ بدون مكتبات إضافية).
- كل بضع دقائق يسأل النظام عن الأسعار عبر HTTPS بمفتاح API. إن لم يتغيّر شيء يرد النظام «لا تغيير» دون إرسال القائمة.
- إذا تغيّرت الأسعار يرسل **التغييرات فقط** لكل ميزان، ثم يبلّغ النظام بالنتيجة (تظهر في المخزون ← الموازين).
- **الأمان:** خادم النظام لا يتصل بالفرع ولا بالموازين، فالبرنامج هو من يتصل. ولا يحتاج الفرع عنواناً ثابتاً أو فتح منافذ.

## التشغيل
1. في النظام أنشئ مفتاح API لمستخدم لديه صلاحية المخزون.
2. أضف الموازين من «المخزون ← الموازين ← إضافة ميزان»، وحدد الأصناف الموزونة ورقم PLU لكل صنف.
3. شغّل البرنامج:
   ```
   python agent.py --server https://erp.example.com --key snr_xxx --interval 5 --out-dir C:\ScalePLU
   ```
   - للتشغيل كمهمة مجدولة في ويندوز استخدم `--once` مع «Task Scheduler» كل 5 دقائق.
   - يحفظ آخر ما أرسله في `scale-agent-state.json`؛ احذفه لإعادة إرسال القائمة كاملة.

## طرق الإرسال
### ملف استيراد (يعمل الآن مع أغلب الموازين)
تكتب الملفات في `--out-dir/<اسم الميزان>/`:
- `plu-all.csv`: كل الأصناف (PLU، الكود، الاسم، الاسم على الميزان، سعر الكيلو شامل الضريبة، الوحدة، الصلاحية، الباركود).
- `plu-changes-*.csv`: التغييرات فقط، مع عمود `Action` (‏U تحديث، D حذف).

برامج الموازين (CAS CL-Works، DIGI، Aclas Link، Rongta، Dahua…) تستورد هذا الملف، وبعضها يراقب المجلد ويرسل للموازين تلقائياً.
إن احتاج برنامجك ترتيب أعمدة أو ترميزاً مختلفاً استخدم `--delimiter` و`--encoding cp1256`، أو أخبرنا بالقالب المطلوب.

### إرسال مباشر للميزان عبر الشبكة
لكل شركة مصنعة بروتوكولها الخاص (وغالباً مكتبة SDK). بعد الحصول على مواصفات طرازك يُنفّذ في `CustomDriver.push()`:
يُرسل لكل صنف رقم PLU والاسم وسعر الكيلو والصلاحية إلى `ip:port` المسجّلين للميزان في النظام.

## صيغة باركود الميزان
تُضبط في «المخزون ← الموازين» ويجب أن تطابق إعداد الميزان، مثلاً `21 PPPPP WWWWW C`:
بادئة 21 + رقم PLU من 5 أرقام + الوزن بالجرام من 5 أرقام + رقم تحقق.
يقرأ النظام هذا الباركود في نقطة البيع (حتى دون اتصال)، والفواتير، والجرد، وفاحص الأسعار.
