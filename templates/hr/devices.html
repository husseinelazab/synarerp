تعمل مع أجهزة ZKTeco والأجهزة المتوافقة مع بروتوكول ADMS / Push (معظم الأجهزة الحديثة التي تحتوي خيار «Cloud Server» أو «ADMS»). الجهاز هو من يرسل البصمات لحظياً إلى النظام عبر الإنترنت — لا يحتاج الفرع عنوان IP ثابتاً ولا برنامجاً على الحاسب.

ضبط الجهاز

  1. سجّل الجهاز أدناه برقمه التسلسلي (SN) من قائمة الجهاز: System Info / معلومات الجهاز.
  2. في الجهاز: Comm. ← Cloud Server Setting (أو ADMS):
    • Server Address / Domain: {{ host }} (فعّل «Enable Domain Name» إن وُجد)
    • Server Port: 80 (أو 443 مع تفعيل HTTPS إن دعمه الجهاز)
    • Enable Proxy: لا
  3. اربط كل موظف برقمه في الجهاز من ملف الموظف ← «رقم الموظف في جهاز البصمة» (أو اجعل رقمه في الجهاز = رقمه الوظيفي).
  4. خلال دقيقة يظهر الجهاز «متصل» هنا، وتصل كل بصمة لحظياً: أول بصمة في اليوم حضور وآخرها انصراف، حسب وردية الموظف.

للأمان: يُقبل فقط جهاز مسجل رقمه هنا ومفعّل. حدد «عناوين IP المسموحة» بالعنوان العام لإنترنت الفرع لمنع انتحال الرقم التسلسلي. الأجهزة التي لا تدعم Push (قديمة) استخدم معها «استيراد سجلات البصمة» من ملف.
