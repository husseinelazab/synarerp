# خريطة النظام: ما المهم وما الاختياري

دليل سريع لكل مجلد وملف في سِينار، مرتب حسب الأهمية. **لا يوجد في المستودع ملفات زائدة أو مؤقتة**؛
كل ما فيه مستخدم، والفرق هو: هل يعمل النظام بدونه أم لا.

| الرمز | المعنى |
|---|---|
| 🔴 | **أساسي**: النظام لا يعمل بدونه. أي تعديل فيه يمس كل الوحدات، فاختبره جيداً |
| 🟡 | **وحدة عمل**: ميزة يعتمد عليها العملاء؛ يعمل باقي النظام بدونها لكن لا تُحذف |
| 🟢 | **اختياري / تكاملات**: يعمل عند ضبطه فقط (مزود رسائل، متجر، جهاز، منصة فاتورة…) |
| ⚪ | **تشغيل وتطوير**: للنشر والتجربة والاختبارات، لا يدخل في منطق النظام |

---

## 1) القلب 🔴 — لا يعمل شيء بدونه

| المسار | ما فيه | أهم الملفات |
|---|---|---|
| `synar/` | إعدادات المشروع والعناوين الرئيسية | `settings.py` (قاعدة البيانات، التطبيقات، المتغيرات `SYNAR_*`)، `urls.py` |
| `core/` | أساس كل شيء: الشركة، الصلاحيات، عزل بيانات الشركات، المستند القابل للاعتماد، الواجهات العامة | انظر الجدول التالي |
| `accounts/ledger.py` | **ترحيل القيود** — كل مستند مالي يمر منه (التوازن، العملات، رقابة الموازنات) | |
| `stock/ledger.py` | **دفتر المخزون والتقييم بالمتوسط المرجح** — كل حركة مخزون تمر منه | |
| `templates/base.html` + `templates/core/` | الهيكل العام للصفحات، والقوائم والنماذج والطباعة العامة | `detail.html`، `form.html`، `list.html`، `print.html` |
| `static/css/erp.css`, `static/js/erp.js` | تنسيق الواجهة كلها، وسلوك النماذج (البنود، الأسعار، الماسح) | |

### داخل `core/` — بالترتيب من الأهم

| الملف | الدور |
|---|---|
| `models.py` | الشركة، السنة المالية، الترقيم، **المستند القابل للاعتماد** (`SubmittableDocument`)، العضويات والأدوار، أسعار الصرف |
| `tenancy.py` + `middleware.py` | **عزل بيانات كل شركة** وتحديد الشركة الحالية والصلاحيات والاشتراك لكل طلب — أخطر ملفين أمنياً |
| `registry.py` + `views.py` + `forms.py` + `display.py` | المحرك العام: أي نوع مستند يُسجَّل في `doctypes.py` يحصل تلقائياً على قائمة ونموذج وصفحة وطباعة واستيراد |
| `invoice.py`, `commercial.py`, `fulfillment.py` | الأساس المشترك للفواتير والمرتجعات، وعروض الأسعار والأوامر، وأذون التسليم والاستلام |
| `permissions.py`, `two_factor.py`, `totp.py`, `auth_backends.py`, `password_reset.py` | الصلاحيات والدخول والأمان |
| `navigation.py` | القائمة الجانبية — **هنا تضيف أي شاشة جديدة للقائمة** |
| `setup_data.py`, `provisioning.py` | دليل الحسابات الافتراضي وتأسيس شركة جديدة |
| `vat.py`, `zatca.py`, `tafqeet.py`, `hijri.py`, `printing.py` | الضريبة ورمز QR والتفقيط والتاريخ الهجري والطباعة |
| `importer.py`, `import_views.py` | استيراد وتصدير Excel لكل المستندات |
| `audit.py`, `notify.py`, `mail.py`, `dashboard.py`, `company_export.py` | سجل التعديلات، التنبيهات، البريد، لوحة التحكم، تصدير بيانات الشركة |
| `api.py`, `api_urls.py` | الواجهة البرمجية REST (`/api/v1/`) — 🟢 لمن يربط أنظمة خارجية |
| `demo.py` | ⚪ بيانات الشركة التجريبية فقط |

## 2) وحدات العمل 🟡

كل وحدة تطبيق Django بنفس النمط:
`models.py` (الجداول والمنطق) ← `doctypes.py` (تسجيلها في المحرك العام) ← `views.py`/`urls.py` (شاشات خاصة إن وجدت)
← `templates/<الوحدة>/` ← `tests.py` و`test_*.py`.

| المجلد | الوحدة | ملاحظات |
|---|---|---|
| `accounts/` | المحاسبة | القيود والسندات والتقارير (`reports.py`)، التسوية البنكية (`bank.py`)، الشيكات (`cheques.py`)، الموازنات (`budget.py`)، الزكاة (`zakat.py`)، العملات الأجنبية |
| `stock/` | المخزون | الأصناف والمستودعات والحركات والجرد؛ وقوائم الأسعار والتشغيلات ووحدات التحويل والباركود |
| `selling/` | المبيعات | العملاء والفواتير والأوامر؛ الفواتير المتكررة؛ رابط الفاتورة العام |
| `buying/` | المشتريات | الموردون والفواتير والأوامر؛ تكاليف الشحن والجمارك؛ قراءة الفواتير بالذكاء الاصطناعي (`ai.py` 🟢) |
| `hr/` | الموارد البشرية | الموظفون والرواتب والإجازات والسلف ونهاية الخدمة؛ الحضور والبصمة (`adms.py` 🟢 لأجهزة ZKTeco)؛ ملف مُدد (`wps.py`)؛ الأهداف والعمولات؛ بوابة الموظف (`portal.py`) |
| `pos/` | نقاط البيع | شاشة الكاشير والورديات والإيصال؛ العمل دون اتصال (`static/js/pos.js`) |
| `saas/` | المنصة 🔴 | الباقات والاشتراكات والتسجيل والمستخدمون ولوحة مدير المنصة — **بدونه لا تُباع الخدمة** |
| `manufacturing/` | التصنيع | قوائم المواد وأوامر الإنتاج وإعادة التعبئة وتخطيط الاحتياجات (`planning.py`) |
| `assets/` | الأصول الثابتة | الإهلاك والبيع والاستبعاد |
| `einvoice/` | الفوترة الإلكترونية (المرحلة الثانية) | 🟡 إلزامي على المنشآت المشمولة؛ يعمل بعد ربط الشركة بمنصة فاتورة |

## 4) التشغيل والنشر والتطوير ⚪

| الملف / المجلد | الاستخدام |
|---|---|
| `run.sh`, `run.bat` | التشغيل التجريبي بضغطة على Mac/Linux أو Windows (قاعدة SQLite وشركة تجريبية) |
| `.devcontainer/` | التشغيل في GitHub Codespaces |
| `Dockerfile`, `docker-compose.yml`, `deploy/`, `.env.example`, `DEPLOY.md` | **النشر للإنتاج**: الخادم، المجدول، Caddy للـ HTTPS، النسخ الاحتياطي المشفر والاستعادة |
| `core/management/commands/run_scheduler.py` | 🔴 في الإنتاج: المهام الدورية (التذكيرات، الفواتير المتكررة، إرسال الفاتورة الإلكترونية، مزامنة المتاجر) |
| `*/migrations/` | 🔴 تعديلات قاعدة البيانات — **لا تُحذف ولا تُعدّل بعد نشرها**؛ تُولَّد بـ `python manage.py makemigrations` |
| `*/tests.py`, `*/test_*.py` | الاختبارات (457 اختباراً): `python manage.py test` قبل أي دمج |
| `requirements.txt` | المكتبات المطلوبة |
| `README.md` | دليل المستخدم والميزات بالتفصيل |
| `docs/SYSTEM_MAP.md` | هذا الملف |

## 5) أين تعدّل عندما تريد…

| تريد | اذهب إلى |
|---|---|
| إضافة حقل لمستند | `models.py` في وحدته ← `makemigrations` ← أضفه في `form_fields` في `doctypes.py` |
| إضافة شاشة للقائمة الجانبية | `core/navigation.py` |
| تغيير شكل الطباعة | `templates/core/print.html` و`static/css/print.css` (والقوالب من «إعدادات الطباعة» في الواجهة) |
| تغيير دليل الحسابات للشركات الجديدة | `core/setup_data.py` |
| تغيير أسعار الباقات | لوحة Django (`/admin/`) ← الباقات |
| إضافة مهمة دورية | أمر في `<الوحدة>/management/commands/` ثم سطر في `run_scheduler.py` |
| إصلاح ربط سلة أو زد | `ecommerce/platforms.py` (قراءة الطلبات) و`ecommerce/api.py` (الاتصال بالمنصة) |

## 6) ما يمكن الاستغناء عنه دون كسر النظام

- **التكاملات 🟢** كلها معطلة افتراضياً؛ إن لم تُضبط لا تعمل ولا تضر.
- **وحدات العمل 🟡** يمكن إخفاؤها عن مستخدم من صلاحياته (الوحدات المسموحة)، وإتاحة نقاط البيع والذكاء الاصطناعي مرتبطة بالباقة.
- **لا تحذف مجلد وحدة** من الكود: جداولها مرتبطة ببقية الوحدات (مثلاً الرواتب ترحّل قيوداً، والمتاجر تنشئ فواتير)، والإخفاء من الصلاحيات أسلم.
- `core/demo.py` و`run.sh`/`run.bat` و`.devcontainer/` للتجربة فقط، لكنها مفيدة للعرض على العملاء فأبقِها.
