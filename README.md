# همت ERP

نظام تخطيط موارد المؤسسات (ERP) **عربي بالكامل** وبواجهة من اليمين إلى اليسار، مستوحى من مفاهيم ERPNext
ومبني على Python / Django.

## الوحدات الحالية

| الوحدة | المحتوى |
|---|---|
| **المحاسبة** | دليل حسابات شجري عربي، قيود يومية، سندات قبض وصرف، دفتر أستاذ عام تلقائي |
| **المبيعات** | العملاء، فواتير المبيعات مع الخصم وضريبة القيمة المضافة وطباعة الفاتورة الضريبية |
| **المشتريات** | الموردون، فواتير المشتريات مع ضريبة المدخلات |
| **المخزون** | الأصناف، المجموعات، الوحدات، المستودعات، أذون الاستلام والصرف والتحويل، تقييم بالمتوسط المرجح |
| **نقاط البيع** | شاشة كاشير سريعة بالباركود، ورديات بجرد النقدية والعجز/الزيادة، دفع نقدي/بطاقة/مختلط، إيصال حراري 80مم مع رمز QR |
| **الموارد البشرية** | الموظفون، الأقسام، المسميات الوظيفية، الرواتب والبدلات |
| **التقارير** | شجرة الحسابات، ميزان المراجعة، دفتر الأستاذ، قائمة الدخل، الميزانية العمومية، إقرار ضريبة القيمة المضافة، أرصدة العملاء والموردين، أرصدة المخزون، دفتر حركة المخزون |

## المفاهيم الأساسية (على طريقة ERPNext)

- **حالة المستند**: كل مستند حركي (فاتورة، قيد، سند، حركة مخزنية) يمر بالحالات: *مسودة ← معتمد ← ملغى*.
  المسودة قابلة للتعديل، والاعتماد يرحّل القيود المحاسبية وحركات المخزون، والإلغاء يعكسها.
- **دفتر الأستاذ العام (GL Entry)** و**دفتر حركة المخزون (Stock Ledger Entry)** يُنشآن تلقائياً ولا يُعدّلان يدوياً.
- **منع المخزون السالب** والتحقق من توازن القيود قبل الاعتماد.
- **سلاسل الترقيم** التلقائية: `SINV-2026-00001`، `PINV-…`، `JV-…`، `PAY-…`، `STE-…`.
- **سجل أنواع المستندات** (`core/registry.py`): إضافة مستند جديد للواجهة تتم بتسجيله فقط، فتُبنى له القائمة
  والنموذج وصفحة العرض والطباعة تلقائياً.

## نقاط البيع (POS)

- **ملف نقطة البيع**: يحدد المستودع وحساب النقدية وحساب البطاقات والعميل الافتراضي ونسبة الضريبة،
  وهل الأسعار شاملة الضريبة، وحدود الخصم، وصلاحية تعديل السعر. يُنشئ `setup_erp` ملفاً افتراضياً باسم «الكاشير الرئيسي».
- **الوردية**: يفتح الكاشير وردية برصيد افتتاحي، وعند الإغلاق يُدخل النقدية الفعلية فيحسب النظام العجز أو الزيادة.
- **البيع**: كل عملية تُنشئ فاتورة مبيعات معتمدة تلقائياً (`is_pos`) تخصم من المخزون وترحّل الإيراد والضريبة
  والتحصيل في نفس اللحظة، فتظهر في كل التقارير المحاسبية والمخزنية دون أي خطوة إضافية.
- **الإيصال**: فاتورة ضريبية مبسطة بمقاس 80مم مع رمز QR بصيغة TLV وفق المرحلة الأولى من متطلبات هيئة الزكاة والضريبة والجمارك
  (يظهر الرمز عند إدخال الرقم الضريبي للشركة).
- **اختصارات**: `F2` للبحث/الباركود، `Enter` لإضافة الصنف الممسوح، `F9` للدفع، `Esc` للرجوع.

افتح نقطة البيع من الرابط `/pos/` أو من زر «نقطة البيع» في القائمة الجانبية.

## اسم النظام

يمكن تغيير اسم النظام المعروض في كل الواجهات دون تعديل الكود عبر المتغير `HAMTERP_NAME`، مثال:

```bash
HAMTERP_NAME="همّة" python manage.py runserver
```

## التشغيل

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py setup_erp --company "اسم شركتك" --tax-id 310122393500003 --admin admin --password "كلمة-مرور-قوية"
python manage.py runserver
```

ثم افتح <http://127.0.0.1:8000> وسجّل الدخول.

لإضافة بيانات تجريبية (عملاء، موردون، أصناف، فواتير، سندات) أضف الخيار `--demo`.

### قاعدة البيانات

يعمل افتراضياً على SQLite. لاستخدام PostgreSQL في الإنتاج عرّف المتغيرات:
`HAMTERP_DB_NAME`، `HAMTERP_DB_USER`، `HAMTERP_DB_PASSWORD`، `HAMTERP_DB_HOST`، `HAMTERP_DB_PORT`
(مع تثبيت `psycopg`)، إضافة إلى `HAMTERP_SECRET_KEY` و`HAMTERP_DEBUG=0` و`HAMTERP_ALLOWED_HOSTS`.

## هيكل المشروع

```
hamterp/    إعدادات المشروع
core/       الشركة، السنة المالية، الترقيم، المستند القابل للاعتماد، سجل المستندات، الواجهات العامة
accounts/   الحسابات، القيود، السندات، التقارير المالية
stock/      الأصناف، المستودعات، دفتر المخزون والتقييم
selling/    العملاء وفواتير المبيعات
buying/     الموردون وفواتير المشتريات
hr/         الموظفون والأقسام
pos/        نقاط البيع: الملفات، الورديات، شاشة الكاشير، الإيصال
templates/  قوالب الواجهة العربية
```

## خارطة الطريق المقترحة

- الفوترة الإلكترونية (فاتورة) — رمز QR والربط مع هيئة الزكاة والضريبة والجمارك
- عروض الأسعار وأوامر البيع والشراء وأذون التسليم والاستلام
- مرتجعات المبيعات والمشتريات (إشعارات دائن/مدين)
- مسيرات الرواتب والإجازات والحضور
- مرتجعات نقاط البيع والعمل دون اتصال (Offline) وربط أجهزة الدفع
- الصلاحيات حسب الأدوار وتعدد الشركات والفروع
- التقويم الهجري بجانب الميلادي
- واجهة برمجية REST
