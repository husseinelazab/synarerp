المصادقة

أرسل المفتاح في الترويسة Authorization: Bearer snr_… (أو X-API-Key). البيانات JSON بترميز UTF-8، والمبالغ نصوص عشرية (مثل "115.00")، والتواريخ YYYY-MM-DD، والروابط بالمعرّف الرقمي id. الحد: 120 طلباً في الدقيقة لكل مفتاح.

curl {{ base_url }} -H "Authorization: Bearer snr_xxxx_yyyy"

يعيد اسم الشركة وكل أنواع المستندات المتاحة لك مع حقولها (المخطط الآلي).

العمليات

الطريقة والمسارالوظيفة
GET /api/v1/{slug}/القائمة: ?q= بحث، ?docstatus=1، تصفية بأي حقل مثل ?customer=5 أو ?posting_date__gte=2026-01-01، ?modified_since=، ?page= و?page_size= (حتى 100)
GET /api/v1/{slug}/{id}/مستند كامل مع بنوده والحقول المحسوبة (الإجماليات، الضريبة، الحالة)
POST /api/v1/{slug}/إنشاء (أضف "submit": true للاعتماد مباشرة)
PATCH /api/v1/{slug}/{id}/تعديل مسودة؛ إرسال البنود يستبدلها بالكامل
DELETE /api/v1/{slug}/{id}/حذف مسودة أو سجل
POST /api/v1/{slug}/{id}/submit/ · /cancel/اعتماد وترحيل · إلغاء وعكس القيود
POST /api/v1/{slug}/{id}/{action}/إجراءات المستند، مثل make_invoice وmake_fulfillment وmake_debit_note — يعيد المستند الجديد في created
GET /api/v1/reports/stock-balance/أرصدة المخزون (?warehouse=، ?item=)
GET /api/v1/reports/account-balances/أرصدة الحسابات كما في ?as_of=

الأخطاء: {"error": {"code": "validation_error", "message": "…", "fields": {"customer": ["…"]}}} مع رموز HTTP: 400 بيانات، 401 مفتاح، 403 صلاحية، 404 غير موجود، 409 مستند معتمد، 429 تجاوز الحد.

مثال: فاتورة مبيعات معتمدة

curl -X POST {{ base_url }}sales-invoice/ \
  -H "Authorization: Bearer snr_xxxx_yyyy" -H "Content-Type: application/json" \
  -d '{"customer": 12, "posting_date": "2026-10-10", "warehouse": 1, "update_stock": true,
       "tax_rate": "15", "vat_category": "S",
       "items": [{"item": 3, "qty": "2", "rate": "150"}],
       "submit": true}'
